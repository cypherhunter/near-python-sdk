# AGENTS.md — near-python-sdk

## Project Overview
Python SDK for NEAR Protocol RPC. Fetches blockchain data (accounts, blocks, validators, gas prices, contract calls) via JSON-RPC.

## Quick Start
```bash
export NEAR_RPC_URL=https://rpc.testnet.near.org  # or mainnet
pip install -e .
python -m near.main view_account root.near
```

## Key Entry Points
- **Library**: `from near.api import NearAPI`
- **CLI**: `python -m near.main <command>` (uses `fire`)

## Core Classes
| Class | File | Purpose |
|-------|------|---------|
| `NearAPI` | `near/api.py` | Main client; properties: `.network`, `.block` |
| `NearNetwork` | `near/network.py` | Status, validators, network info |
| `NearBlock` | `near/block.py` | Block/chunk queries by height/hash/finality |
| `Account` | `near/models/account.py` | Parsed account view (amount in NEAR, not yoctoNEAR) |
| `GasPrice` | `near/models/gas.py` | Gas price in NEAR |

## Environment
- `NEAR_RPC_URL` — RPC endpoint (default: `https://rpc.mainnet.near.org`)
- Testnet: `https://rpc.testnet.near.org`

## Common Commands (uv)
```bash
# Install uv (once)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Sync dependencies (creates .venv)
uv sync --dev

# Install in development mode
uv pip install -e .

# Format code
uv run black .

# Run CLI
uv run python -m near.main view_account <account_id>
uv run python -m near.main call_contract_func <account_id> <method_name> <args_json>
uv run python -m near.main gas
uv run python -m near.main network validators

# Add/update dependencies
uv add requests@latest
uv add --dev pytest
uv remove fire

# Lock file (uv.lock) is committed
uv lock
```

## Gotchas
- `Account.amount` and `Account.locked` return **NEAR** (divided by 10²⁴), not yoctoNEAR
- `call_contract_func` args must be JSON-serializable dict/list; internally base64-encoded
- RPC errors raise `NearException` with raw error payload
- Retries configured for 5xx (502, 503, 504) with exponential backoff
- `finality` param: `"optimistic"` (default) or `"final"`
